# Product imagery

Assets: `public/assets/jewellery/*.svg` – one illustration per jewellery type (necklace, ring, jhumka, bangle, chain, coin, signet, mangalsutra, pendant, stud, bracelet, nosepin, choker, haram, tennis, navaratna).

These are illustrative vector drawings, not photographs of actual stock. Each item's `image` field (see `lib/data.mjs`) points to one of them. Replace it with a real product photo URL to show actual stock; if an image fails to load, the interface falls back to a neutral icon.
